# Todo List 📝

A simple and user-friendly Todo List web application.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean design
- Easy to use

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📁 Project Files

- `todo.html` – Main webpage
- `todo.css` – Styling and design
- `todo.js` – Todo List functionality

## ▶️ How to Run

1. Download or clone this repository.
2. Open `todo.html` in a web browser.
3. Start adding your tasks.

## How It Works

The application uses JavaScript to add, delete, search, filter, and complete tasks.

Tasks are stored in the browser's LocalStorage, so they remain saved even after refreshing the page.
